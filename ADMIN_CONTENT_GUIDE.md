# MAGIC Youth Admin Content Guide

Welcome to the MAGIC Youth Admin Portal. This guide explains how to properly manage official organizational content.

## 1. Content Creation Flow (Order of Operations)

To ensure all relationships work correctly, please create content in this order:

1. **Units**: Create your institutional units first (e.g., "ALC MAGIC YOUTH", "ALIET MAGIC YOUTH").
2. **Academic Years**: Under each Unit, create the active Academic Years (e.g., "2025–2026").
3. **Teams**: Once a Unit and Academic Year exist, you can create a Team (e.g., "Executive Board").
4. **Members**: Finally, you can add actual students to those Teams.

## 2. Managing Teams & Members

- **Important Rule**: The public Teams page automatically filters by **Unit + Academic Year**. You do not need to manually link members to a specific webpage. Simply assign them correctly in the Admin Portal, and they will dynamically appear in the right place.
- **Archiving**: When an academic year ends, simply create a new Academic Year and build the new teams. Old teams will remain safely in the database and can be viewed publicly by selecting the past year.

## 3. Adding Events

- Ensure you assign the event to the correct Unit and Academic Year.
- **Statuses**:
  - `Upcoming`: For future events. Will display prominently on the public homepage and events page.
  - `Ongoing`: For events currently taking place.
  - `Completed`: For past events.
- **Posters**: Only upload official event posters. Supported formats: JPG, PNG, WEBP, PDF, HEIC.

## 4. Gallery Photos

- You can upload multiple photos at once.
- Always select the relevant **Unit** and **Academic Year**.
- You can optionally link photos to a specific **Event** or assign them an **Album** name (e.g., "Annual Day 2025").

## 5. Documentation

- Use this section for official forms, reports, or materials.
- **Visibility**:
  - `Public`: Anyone can download it from the Documentation page.
  - `Admin Only`: Reserved for internal storage.
- Download tracking happens automatically when a user clicks the download link.

## 6. Join Requests

- Public users use the "Join" page to submit applications.
- Review their submitted resumes (PDFs) and profile photos directly in the Admin Portal.
- Update their status (`Pending`, `Reviewed`, `Accepted`, `Rejected`) to track the recruitment pipeline.

## 7. Supported Files & Recommendations

- **Images** (Profile Photos, Event Posters, Gallery): `.jpg`, `.jpeg`, `.png`, `.webp`, `.heic`, `.heif`. Maximum size: 5MB per image.
- **Documents** (Resumes, Documentation): `.pdf`, `.docx`, `.xlsx`, `.csv`. Maximum size: 10MB per document.
- **Recommendation**: Compress large photos before uploading to ensure the website loads lightning-fast for users.

## 8. Data Integrity (No Fake Content)

- **Do NOT** upload placeholder text ("Lorem ipsum"), fake statistics, or dummy events.
- The public website dynamically calculates statistics (e.g., "Number of Units", "Total Events"). If you haven't uploaded an event, the website will gracefully hide or format the empty state without lying to users.
